# Framework lessons — the incident ledger behind the generic doctrine

**Since 2026-09-27 the prompts the framework generates carry RULES, never
incidents.** A Fleet Supervisor, a project supervisor, a coding lane or a chat
turn reads a project-agnostic core doctrine (`backend/src/modules/crossmodel/platform/core-doctrine.ts`),
a live harness-facts block (`platform/framework-facts.ts`), its OWN project's
brief (`platform/project-brief.model.ts` + `.loader.ts`) and a generic role
profile (`platform/role-profiles.ts`), composed by `platform/prompt-layers.ts`.
The dated narratives that produced each rule — which project stalled, which
ticket, which owner message — live HERE and in the code comment above the rule.
The prompt-hygiene lint (`platform/prompt-hygiene.test.ts`) fails CI on a date,
ticket / oq_ / cf_ id, project name, model id, owner-quote marker or env toggle
inside a generic block.

## How repair loops add a lesson from now on

`platform/lesson-writer.ts recordLesson({ repoRoot, ruleId, section, rule, incident, date, ticket? })`
is the ONLY doctrine-append path:

1. it appends the GENERIC rule sentence as a bullet under the named core section
   (`standing` / `scope` / `gate` / `evidence` — `CORE_SECTION_ANCHORS`);
2. it appends the dated incident row to the table below (under the anchor);
3. it runs the hygiene checks on the rule sentence and REFUSES an inline date,
   id, project or model name, owner-quote marker or env toggle.

A ticket-dispatch lane, the Framework Operator lane, or an interactive session
that wants a supervisor to learn from a mishap calls it (CLI:
`node backend/dist/modules/crossmodel/platform/lesson-writer.js --ruleId <area.name> --section <standing|scope|gate|evidence> --rule '<generic sentence>' --incident '<what happened>' --date YYYY-MM-DD [--ticket <id>] [--label '<RULE LABEL>']`)
and ships the diff through the normal PR gate. The `[FLEET_FACTS]` growth path
and `fleetChangelogNote()` are retired: `supervisor-doctrine.ts` is frozen for
the `PROMPT_LAYERING_DISABLED=1` path only and nothing appends there.
